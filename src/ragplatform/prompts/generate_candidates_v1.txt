{taxonomy}

Rules for an ANSWERABLE target category (anything except "unanswerable"):
- The question must be answerable from the passage alone, and the reference answer must be fully supported by the passage. Do not use outside knowledge.
- Write the question the way a user would ask it: do not mention "the passage", "this section" or "the text". Prefer questions that name the PEP or the concept so they make sense without the passage.
- The reference answer is one to three sentences, specific, and quotes exact names, values and identifiers from the passage where they matter.
- Match the target category's decision rule. If the passage cannot support a question of that category, pick the closest category it can support and say so in the category field.

Rules for the "unanswerable" target category:
- Write a plausible question about Python or PEPs that is related in topic to the passage but whose answer is NOT in the passage and is unlikely to be anywhere in a corpus of PEP documents (for example implementation details of a specific library, benchmark numbers, dates of conference talks, opinions of named people, or a false premise).
- The reference answer must be exactly: "The corpus does not contain this information."

Set "difficulty" to easy, medium or hard: easy if the answer is a single stated fact, medium if it needs a whole paragraph, hard if it needs synthesis or careful reading.

Reply with a single JSON object and nothing else:
